## 1. Общее описание

Сайт MVST использует точно такое же API, как и сайт Tsum, с единственным ключевым отличием:  
→ Фильтрация товаров по бренду является обязательной и встроенной в каждый запрос.

Это означает, что все эндпоинты API, используемые на Tsum, доступны и на MVST, но каждый запрос к API обязательно должен содержать параметр `brand=mvst` (или аналогичный идентификатор бренда, определяемый в конфигурации), чтобы фильтровать результаты исключительно по товарам бренда MVST.

## 2. Доступные страницы и их структура

| URL-шаблон | Назначение |
|-----------|------------|
| /catalog/men | Каталог мужской одежды (все товары бренда MVST для мужчин) |
| /catalog/women | Каталог женской одежды (все товары бренда MVST для женщин) |
| /catalog/men/:SLUG | Подкатегория мужской одежды (например, `/catalog/men/shirts`) |
| /catalog/women/:SLUG | Подкатегория женской одежды (например, `/catalog/women/dresses`) |
| /catalog/sel/:SELLECTION | Выборка (коллекция/сборник) товаров для всех полов (например, `/catalog/sel/summer2025`) |
| /catalog/sel/:SELLECTION/:SLUG | Выборка с фильтрацией по подкатегории (например, `/catalog/sel/summer2025/shoes`) |

> Примечание:  
> Параметр :SLUG — это URL-дружественный идентификатор категории (например, shirts, dresses, `shoes`).  
> Параметр :SELLECTION — идентификатор коллекции (например, spring2025, `limited-edition`).

## 3. Отображение элементов интерфейса

### На десктопе (≥1024px):

- Слева (стабильная колонка):  
  → Категории (иерархическая навигация: Мужчины → Верхняя одежда → Кофты и т.д.)  
  → Фильтры не повторяются — категории и фильтры разделены по зонам.

- Сверху (над списком товаров):  
  → Фильтры (бренд, размер, цена, цвет, материал и т.д.)  
  → Фильтры отображаются как горизонтальная панель с чекбоксами / выпадающими списками  
  → Возможна фильтрация по нескольким параметрам одновременно  
  → Поддержка сброса фильтров

- Центральная зона:  
  → Список товаров (сетка 3–4 колонки)  
  → Пагинация

### На мобильных устройствах (<1024px):

- Сверху (над списком товаров):  
  → Категории отображаются как горизонтальный скролл-бар с тегами (например: *Кофты | Джинсы | Обувь*)  
  → При клике на категорию — открывается модальное окно или перенаправление на соответствующий URL

- Сверху над списком товаров:  
  → Фильтры — доступны в списке селектов
  → При нажатии открывается попап с возможностью выбора параметров  
  → После применения фильтров — обновляется список товаров без перезагрузки страницы

- Центральная зона:  
  → Список товаров (две колонки, карточки в стиле "список")  
  → Пагинация
